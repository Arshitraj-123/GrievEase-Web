## Security Verification Highlights

1. **Zero Client Trust**: All validations are re-executed server-side via Zod schemas and NestJS ValidationPipes with `whitelist: true` and `forbidNonWhitelisted: true` to prevent mass-assignment.
2. **XSS & SQLi Defense**: Parameterized SQL queries with `$1, $2` placeholders throughout all pg pool executions. React DOM escaping prevents DOM XSS; user-provided HTML is disallowed.
3. **File Upload Hardening**:
   - Magic-byte verification (`file-type` header check) prevents renamed `.exe` / `.html` execution.
   - Images re-encoded via Sharp to strip EXIF GPS coordinates, device identifiers, and embedded malicious payloads.
   - Saved to MinIO S3 storage using cryptographically random UUID v4 keys.
   - Strict `Content-Disposition: attachment` or `inline` with `Content-Security-Policy: default-src 'none'` on storage buckets.
4. **Multi-Language Unicode Resilience**: Verified against complex Hindi/Devanagari character combinations (zero-width joiners `U+200D`, halant combinations, combining marks) without truncation or regex corruption.
